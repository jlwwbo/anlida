# 安粒达 · ANLIDA

> 论粒给药，不拆原包装。

面向多重用药人群的固体制剂自动取药器——**唯一让药留在原厂铝塑泡罩板里、直到服用前一刻才被取出的**那一类。
这个仓库是它的两个网页：一页讲清楚**为什么**，一页让人**把机器转起来看**。

复客松 · 华润三九杯 AI 医疗健康黑客松。设计与论证文档在坚果云
`54-小技术项目/11-复客松/`，本仓只放能跑的东西。

---

## 跑

```bash
npm run dev        # = node serve.mjs，零依赖，默认 8732 端口
open http://localhost:8732
npm test           # serve.mjs 的路径越界自检
```

**没有后端。** 整站是两个 HTML + 六个 ES module + vendored 的 three，
扔进任何静态托管（阿里云 ESA Pages / Vercel / GitHub Pages / 一个 nginx 目录）就能跑。
`serve.mjs` 只为本地预览存在——ES module + importmap 在 `file://` 下会被 CORS 拦，必须走 HTTP。

### 部署

`esa.jsonc` 是阿里云 ESA Pages 的构建配置：无依赖、无构建步骤、仓库根目录即静态资源目录。

```jsonc
{ "name": "anlida", "installCommand": "", "buildCommand": "", "assets": { "directory": "./" } }
```

⚠️ **页面里的资源路径一律用根绝对路径**（`/css/…`、`/src/…`、`/vendor/…`），不用 `./`。
ESA Pages 会把 `/structure.html` 重定向到 `/structure/`，相对路径在那之后会解析到
`/structure/css/…` 而全部 404。JS 模块之间的 `./machine.js` 不受影响——那是相对模块自身
的 URL 解析的，不是相对文档。

## 结构图怎么玩

| | 桌面 | 手机 |
|---|---|---|
| **转视角** | 拖拽 / 滚轮 | 单指拖 / 双指缩放 |
| **看零件** | 悬停出卡片，点一下钉住 | 点零件 → 底部抽屉；位移 < 8 px 才算点选，否则交给转视角 |

**九个用药画像**来自《14-用药画像案例集》。选中一个人，仓里就装他的药，并算出三个数：

| | 板装药 | 占槽 | 换板周期 | 卡在哪 |
|---|---:|---:|---:|---|
| P5 老赵（核心，「平均 9.1 种」的化身） | 9 种 | 18/20 | 10 天 | 二甲双胍，一日两次 |
| P6 李奶奶（最该买的一个） | 3 种 | 9/20 | 21 天 | 另有 2 种设备管不了：碳酸钙瓶装、骨化三醇软胶囊会被顶针压破 |
| P9 老周（能力上限那条线） | 12 种 | 12/20 | **2 天** | 多巴丝肼每日 3–4 次。**这个数自己会说话** |

装填演示 = 掀盖 → 托盘从上方逐个落进两片隔板之间。板从上面插，因为前面 z 向 9–215 mm 全被滑车占着。

## 文件

```
index.html              landing 骨架（文案全部由 JS 注入）
structure.html          结构图骨架
css/tokens.css          设计令牌（含深色），两页共用
css/landing.css         landing 版面
css/structure.css       结构图版面
src/landing-content.js  landing 的全部文案与数据 —— 改说法只动这个文件
src/landing.js          文案注入、滚动进场、失效模式图、hero 的 3D
src/profiles.js         九个用药画像 + 六种板型 + 装载方案与换板周期的计算
src/parts.js            19 个零件 + 六段时序
src/machine.js          几何装配（单位 mm，直接用文档里的尺寸）+ pose(t) + poseLoad(t)
src/main.js             结构图页：渲染、拾取高亮、爆炸、时序、画像、抽屉
serve.mjs               本地预览用的零依赖静态服务（+ serve.test.mjs）
vendor/three/           three r180，已 vendored，离线可跑
```

两页共用 `machine.js`。landing 的 hero 是同一台机器，走**精简档**（`buildMachine({lite:true})`，不建隔板、卡扣、定深针）。

## 设计口径

- **纸为底，机器是唯一的白，药是唯一的饱和色。** 画布透明，底色交给 CSS。
- 外观三段：**石墨底座（四周内缩 7 mm 留阴影缝）+ 暖骨白机身 + 悬挑 3 mm 的圆角顶盖**。
  不用纯白——**纯白 + 直角 = 医疗器械的配色**，而付费方是家属，机器要摆在客厅或厨房。
- 前脸左 2/3 剖开给结构看，右 1/3 是**取药龛**：出药口 → 滴水格栅 → 可取下的**浅碟**。
  是碟不是杯：药片最小 φ5 mm，手抖的老人从深杯里捏不出来。
- 字：标题 Noto Serif SC，一切数字与标号 Space Mono（沿用 `gks` 的口径），正文走系统中文黑体。
- 仓里故意放不同板型（2×5 片剂 / 1×7 胶囊 / 3×4 小片 / 长条片 / 双铝不透明 / 2×7 薄膜衣片），
  这是「不同板都能插进同一个槽」那句话的视觉证据。**双铝那种两面都不透光**——正好对上「相机看不见药、只能靠泡窝外形判」。

## 性能预算

hero 是装饰性的，就按装饰性的预算给：

| | landing hero | 结构图 |
|---|---|---|
| 像素比 | 封到 **1.25** | 至 2（触屏 1.75） |
| 实时阴影 | **不做**，用一张径向渐变贴图当接触阴影 | 做，2048（触屏 1024） |
| 帧率 | **30 fps 封顶**；滚动中 140 ms 内一帧不画 | 不限 |
| 切后台 | 停画 | 停画 |

起因是量出来 hero 在 retina 上按 1.75 渲染 = 2800×1397 ≈ **390 万像素**，外加每帧一遍阴影渲染，
主线程跟滚动抢时间。改完 200 万像素，滚动中最长帧 17.7 ms。

## 哪些是示意，哪些不是

诚实分档，答辩会被问：

- **动画放慢了约两倍**。真实节拍 4.1 s/粒，为看得清而放慢。
- **白模不表达表面处理与造型细节**——咬花、分模线、拔模角、螺丝位一概没有，那些要等结构工程师。
- **实物药仓不可透视**。页面上前脸剖开是为了让人看见里面，不是产品状态。
- **每板粒数取的是常见值**。《14》原文给的是区间（同一个药 7 / 14 / 20 / 28 都有），
  换板周期因此是量级估计，不是承诺。
- **泡窝高度上限 12 mm 是推断值**，没实测。它要是错了，17 mm 槽距和 340 mm 仓长都要重算。
- **整套力学模型还没上过台架。**《17》第九节那份实测清单是这个项目最该先花钱的地方。
