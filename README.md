# 安粒达 · 破板取药机构结构图

《复客松 / 11-复客松 / 13-破板取药机构》v2.9 的可交互白模。一页静态站，无构建步骤。

```bash
python3 -m http.server 8000     # 必须走 HTTP：ES module + importmap 在 file:// 下被 CORS 拦
open http://localhost:8000
```

## 怎么看

| 操作 | 看到什么 |
|---|---|
| 拖拽 / 滚轮 | 转视角、推拉 |
| 悬停零件 | 右上卡片给名称、关键数、状态（已定 / 待验证 / 待设计） |
| 点击零件 | 钉住卡片；再点空白处松开 |
| 左下六段 | 一次取药的时序，点任一段跳过去 |
| 底部「拆开」 | 爆炸图；「外壳」收掉壳体 |

## 结构

```
index.html        页面骨架与刊头文案
styles.css        设计令牌（含深色）、刊头、时序轨、零件卡、操作台
src/parts.js      19 个零件的名称 / 关键数 / 状态 ——《13》的文字在这里，改文案只动这个文件
src/machine.js    几何装配（单位 mm，直接用《13》3.3 与 4.4 M1 的尺寸）+ 时序函数 pose(t)
src/main.js       渲染、光照、拾取高亮、爆炸、时序播放、UI 绑定
vendor/three/     three r180（three.module.js + OrbitControls + RoomEnvironment），已 vendored，离线可跑
```

## 设计口径

- **纸为底，机器是唯一的白，药是唯一的饱和色。** 画布透明，底色由 CSS 画；地面只接阴影（`ShadowMaterial`）。
- 字：标题 Noto Serif SC，一切数字与标号 Space Mono（沿用 `gks` 的口径），正文走系统中文黑体。
- 状态只有三档，用形而不只用色：实心 = 已定，琥珀 = 待验证，空心环 = 待设计。
- 20 个槽里故意放了四种板型（2×5 片剂 / 1×7 胶囊 / 3×4 小片 / 长条片），这是「不同板都能插进同一个槽」那句话的视觉证据。

## 与文档的对应

几何与数值全部来自《13》，不在这里另立一套：

| 这里 | 出处 |
|---|---|
| 380 × 250 × 180，槽距 17 mm × 20 | 13 §3.3、§4.4 M1、§4.5 ② |
| 无夹爪：薄推杆 + 磁铁，推出行程兼列对位 | 13 §4.4 M1 |
| 马蹄支撑座 C 形、缺口朝下、净空 14 mm | 13 §S1、§4.8 D |
| 60 N 力流闭合在 C 形滑车内部 | 13 §3.1 |
| 双侧相机 + 漫射频闪，不停车 | 13 §4.8 B |
| 六段时序与 4.1 s/粒 | 13 §五、§5.5 |
| 70 N 作动器、6 mm² 接触面积判据、11 m/s 出膛上界 | 17 §四、§五 |

动画为看得清而放慢，约为真实节拍的两倍。
